# Подготовка к GitHub Pages

Публичный лендинг может работать без Cloudflare: Source — Deploy from a branch, ветка `main`, папка `/ (root)`. В корне есть `.nojekyll`, а оптимизированные MP4 находятся в `public/pages-media/`. Админка без API остаётся локальной.

`npm run build:pages` также собирает автономный лендинг; `NEIR_API_URL` необязателен. Если указать адрес опубликованного Worker, сборка переключит контент и исходные медиа на API. Остальные команды ниже нужны только для подключения облачной админки.

## Архитектура

- Лендинг: `https://razuv.github.io/neir/`.
- Админка: `https://razuv.github.io/neir/admin/`. GitHub Pages использует префикс проекта `/neir/`; для корневого `/admin` нужен отдельный домен.
- API, проверка пароля, сессии и тексты: Cloudflare Worker + D1.
- Изображения и видео, включая исходные ролики: Cloudflare R2. Видео не коммитятся в Git.
- Секреты не входят в Pages-сборку. В публичных файлах содержится только URL API.

## Что нужно до публикации

1. Активировать R2 в подключённом Cloudflare-аккаунте. База `neir-content` уже создана, её ID указан в `backend/wrangler.jsonc`.
2. Создать bucket `neir-media-uploads`, применить `backend/schema.sql` к удалённой D1 и загрузить исходные ролики в R2 под ключами `original/video-1.mp4` … `original/video-7.mp4` (третий — `video-3.mov`). Привязка bucket уже прописана в Worker.
3. Установить `ADMIN_PASSWORD_HASH` как секрет Worker из `backend/.dev.vars`; пароль и `.dev.vars` не отправлять в репозиторий. Опубликовать Worker. `ALLOWED_ORIGINS` уже разрешает `https://razuv.github.io`.
4. Перенести нужный локальный контент и медиа в облако до переключения на него. Локальные URL с портом 8787 не подходят для публичного сайта. До этого на публичном сайте используются тексты из `content-defaults.js`.
5. Подключить GitHub с правом записи в `razuv/neir`. В репозитории выбрать Settings → Pages → GitHub Actions. Создать repository variable `NEIR_API_URL` с реальным HTTPS-адресом опубликованного Worker, без пути `/content`.
6. Отправить исходники в `main`. Workflow **Publish NEIR MEDIA** запускается только вручную через Actions → Run workflow; обычный push ничего не публикует.

## Проверки и сборка

```sh
npm run check
npm test
npm run build
```

Для проверки production-сборки:

```sh
NEIR_API_URL=https://РЕАЛЬНЫЙ-АДРЕС-API npm run build:pages
```

`build:pages` использует статический контент, если URL API не указан. Если URL указан, он проверяется на HTTPS, отсутствие localhost, секретов и лишнего пути. В готовом `dist/` находятся только статические файлы, `/admin/`, `.nojekyll`, robots и sitemap; исходные видео и серверные секреты исключены.

## Локальный визуальный редактор

Запустить `npm run dev` и отдельно `npm run api:dev`; открыть `http://localhost:5173/admin/`. Логин `neiradmin`, пароль — в игнорируемом файле `.admin-credentials`.

Редактор открывает настоящий лендинг в iframe. Нажмите текст и печатайте прямо на сайте, либо измените значение в инспекторе справа. Выбор кейса открывает его описание и медиа: файлы можно бросать в инспектор или на обложку кейса, менять местами и убирать. Кнопки «Десктоп» и «Телефон» меняют реальную ширину iframe (1440 / 390 px) с автоматическим масштабом. Режим «Просмотр» отключает подсветку и правку текста. Все действия меняют черновик до нажатия «Применить на локалке» / «Опубликовать».
