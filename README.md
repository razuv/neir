# NEIR MEDIA

Адаптивный лендинг по ТЗ и Main_1440.png. HTML, CSS и JavaScript без зависимостей.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5173. Node.js 20+.

```sh
npm run check
npm run build
```

Статическая сборка создаётся в `dist/` и может размещаться на обычном статическом хостинге. `server.mjs` — локальный сервер, поддерживает range-запросы для видео.

## Реализовано

- 7 услуг: по умолчанию раскрыт только первый блок; цены подтверждены пользователем.
- Два спецпредложения, состав услуг, кейсы (4 на desktop, 3 на mobile), раскрытие и модальные подробности.
- AI-продакшн, Academy, результаты, основатель, аудитории, преимущества, клиенты, этапы и контакты.
- Bounded и TikTok Sans из предоставленной папки; локальные логотипы и WebP.
- Telegram @neirmedia, WhatsApp, телефон, предзаполнение услуги в форме.
- Hero: IMG_8579, muted autoplay/loop, SVG-уголок #0057FF в Overlay.
- Вертикальные видеокарусели: muted autoplay в видимой области, переход после окончания и по боковым карточкам, свайп, пауза и отдельный звук; вне экрана воспроизведение приостанавливается.
- Фотогалереи с нижними индикаторами, кликом, клавиатурой и свайпом.
- Фиксированный хэдер с инверсией через difference; белые SVG-маски логотипов.
- Кастомный список бюджета с клавиатурным управлением и передачей значения в форму.
- Микроанимации и лёгкий параллакс заголовков от курсора с поддержкой reduced-motion.
- Клавиатурная навигация, native details/dialog, Escape, reduced-motion.

## До публикации

Метрика и серверная отправка заявок не подключены по просьбе пользователя. Сейчас форма открывает черновик в почтовом приложении и не сообщает о доставке заявки. Настройки находятся в `config.js`. Для будущего подключения API нужны endpoint, опубликованные политика и согласие; успех показывается только после успешного HTTP-ответа. Юридические ссылки пока показывают информационное окно, а не окончательные юридические документы.

Портрет основателя подключён из Rectangle 20.png. Отдельные исходники фотографий Самоката/Арх Москвы не предоставлены: для двух фотографий используются CSS-фрагменты WebP-копии макета. Фотогалереи используют общую подборку этих двух изображений с подписями. При наличии исходников заменить функцию `art()` в `app.js`. Для неопознанных кейсов использованы названия, без чужих стоковых фотографий. Исходные видео перечислены в `public/media/manifest.json`; принадлежность конкретным клиентам не предполагается. Для публикации рекомендуется подготовить компактные MP4/WebM и индивидуальные постеры; исходные видео сохранены без изменений. Hero загружается сразу, видеокарусели — при появлении в видимой области.

Статистика взята из подробного раздела 12 ТЗ; исторические результаты кейса Лай Лай Лэнд сохранены из раздела 9. В документе эти значения различаются.

Проверены синтаксис, production-сборка и DOM-сценарии: раскрытие услуг и кейсов, modal/Escape, выбор услуги, Telegram, переключение фотографий и роликов, переход по окончании видео, кастомный бюджет и отсутствие ошибок JavaScript. Визуальная проверка намеренно не проводилась по просьбе пользователя.


## Локальная админка

Адрес: http://localhost:5173/admin/ . Логин `neiradmin`. Сгенерированный пароль находится в `.admin-credentials` (файл игнорируется Git). В `backend/.dev.vars` хранится только хеш.

Один раз подготовить локальную базу:

```sh
npx wrangler d1 execute neir-content --local --file backend/schema.sql --config backend/wrangler.jsonc
```

В двух терминалах запустить:

```sh
npm run api:dev
npm run dev
```

API на порту 8787 использует только локальные эмуляторы D1 и R2. Страница определяет localhost автоматически. Кнопка «Применить на локалке» сохраняет тексты и кейсы в локальную базу; после этого обновите лендинг. «Предпросмотр» показывает ещё не сохранённый черновик.

Админка содержит тексты по разделам и поиск, отдельные услуги, добавление/удаление/порядок кейсов, drag&drop-загрузку медиа, подписи и обложки, SEO и контакты. Одна загрузка — до 95 МБ. Допускаются JPG/PNG/WebP/AVIF/GIF/MP4/WebM/MOV. Загружаемые SVG не допускаются. Черновик хранится в браузере; можно скачать JSON-копию контента.

Публикация в интернет приостановлена по просьбе пользователя. Workflow GitHub Pages подготовлен, но исходники не отправлены. Cloudflare-аккаунт авторизован и база `neir-content` создана; R2 в аккаунте требует отдельной активации. Локальная админка работает без активации облачного R2.

Проверки: `npm run check`, `npm test` (схема, пароль, доступ к записи, блокировка попыток, ревизии, отзыв сессии и загрузки), `npm run build`. Локальная интеграционная проверка подтвердила вход, редактирование, новый кейс, загрузку PNG, предпросмотр, применение и отображение на лендинге; HTML в тексте не исполняется. Визуальная проверка не проводилась.


## Визуальное редактирование и Pages

Админка теперь открывается в режиме «Редактор сайта»: нажмите текст на лендинге и печатайте прямо в макете. Панель справа синхронизируется с выбранным текстом, услугой или кейсом. Фото и видео можно перетащить прямо на кейс; медиа и их порядок редактируются справа. Десктоп/телефон переключают реальные размеры iframe 1440/390 px. Отдельные формы «Все тексты», «Услуги», «Кейсы», «Настройки» доступны как дополнительные режимы. Изменения остаются черновиком до явного сохранения.

Сборка Pages: `npm run build:pages` с переменной `NEIR_API_URL`. Она проверяет HTTPS-адрес API, исключает исходные видео и серверные файлы, поддерживает префикс `/neir/`, добавляет `.nojekyll`, canonical, robots и sitemap. Workflow публикации запускается только вручную. Подготовка и внешние зависимости описаны в `PAGES_DEPLOYMENT.md`.

Проверены: редактирование в iframe и правой панели, услуги и кейсы, мобильный/десктопный размер, загрузка файла и drop прямо на кейс, обновление обложки, режимы просмотра/редактирования, отсутствие автоматической публикации и ошибок JavaScript. Снимки страницы и визуальная проверка не выполнялись.


## Автономная публичная версия

Лендинг работает на GitHub Pages без API Cloudflare. Для публикации из ветки: `main` → `/ (root)`; `.nojekyll` отключает Jekyll. В `public/pages-media/` находятся оптимизированные H.264/AAC MP4 для hero и каруселей, отдельные от исходных видео. На localhost используются оригиналы, на Pages — оптимизированные версии.

`npm run build:pages` допускает отсутствие `NEIR_API_URL` и собирает полноценную статическую версию. При заданном HTTPS URL API подключается облачный контент. Админка продолжает работать локально, пока облачный API не подключён.
